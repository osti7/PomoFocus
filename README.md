# PomoFocus | Pomodoro Timer
Minimalist and modern pomodoro timer. 

## Features

- 25 minute FOCUS and 5 minute BREAK loop
- Purple neon theme
- Two buttons for control
- Sound feedbacks

## How It Works

- Open index.html
- Use buttons for start
- When FOCUS finished it's automatically starts BREAK
