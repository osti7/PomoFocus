## Features

- 25 minute FOCUS and 5 minute BREAK loop
- Switchable dark/light theme
- Purple neon theme
- Three buttons for control
- Sound feedbacks

## How It Works

- Open index.html
- Use buttons for start
- When FOCUS finished it's automatically starts BREAK
